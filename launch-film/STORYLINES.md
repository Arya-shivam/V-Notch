# V-Notch launch film — storylines

**Recommendation: The notch as a switch.** Real V-Notch footage hands off to exact feature facts; each problem question leads into the matching capability, without invented UI or private data.

## 1. The notch as a switch — selected

- **Device / form:** The notch is the carrier between genuine V-Notch footage and source-backed capability proofs. Kinetic type and a drawn green rule expose new features without pretending to show their unavailable UI.
- **Viewer:** Start on settings footage with “Checking usage provider by provider?”; the notch opens into AI-provider support, local PC readings and storage. End on the official showcase image and a clear Windows preview release link.
- **First two seconds:** Official settings capture, notch trace, and the hook snaps in from the left. A short whoosh peaks one frame after the iris begins.
- **Beats:** Provider problem → AI usage proof and Codex / Claude Code / Kimi Code → PC settings problem → CPU / RAM / network facts → drive-space problem → selected-drive capacity and all-disk activity → official product showcase → release card.
- **Look:** Official media and mark; white/black/grey with restrained green accents, oversized Inter and fast staggered text. No mock widget UI, charts or sample values.
- **Sound:** Fast no-vocal local MusicGen bed (128.4 BPM; trimmed from 6.9 s so its rising accent lands on the 16.4 s end-card wipe), plus a timed iris whoosh and product-reveal impact. Final mix −16.1 LUFS, −1.7 dBTP, zero clipping; measured, not heard.

## 2. One notch, many signals

- **Device / form:** A single desktop moment; one continuous take. The notch stays present while facts replace separate usage and system checks.
- **Viewer:** Hold on one real V-Notch screen, then pull out to a typographic list of exact local measurements.
- **First two seconds:** The real desktop frame is already on screen; the notch is visible at the top edge while “At a glance” lands.
- **Beats:** Desktop need → V-Notch appears → provider names → native Windows measurements → local storage → end card.
- **Look:** Captured desktop imagery and clean monochrome type; no fake numbers or widget drawings.
- **Sound:** No voice. A single soft pulse would make this a different, slower film.

## 3. The notch goes to work

- **Device / form:** The product mark as a relay; cut from real app footage to the official logo and download action.
- **Viewer:** Real V-Notch footage anchors the brand; short lines answer what the new widgets read and where those readings come from.
- **First two seconds:** Open on actual notch footage with no title; “Your desktop, in view” lands after the first beat.
- **Beats:** Notch → AI-provider sources → local system APIs → drive stats → one-line claim → download end card.
- **Look:** Actual product media, white page, black type and official mark.
- **Sound:** No voice. A percussive pulse with a final mark impact would create a different cut.

## Production assumptions

- 23.1 seconds, 1920×1080, 30 fps; no voiceover. Use only real V-Notch media and README-verified facts. Never present illustrative quotas or local-machine readings. The live UI for new widgets is unavailable, so use factual typography instead of a fabricated interface.
- The end card links to the GitHub Releases page and discloses “Unofficial fork · unsigned · Windows x64.” The final render `renders/v-notch-launch-cinematic.mp4` includes MusicGen and two timed SFX.
